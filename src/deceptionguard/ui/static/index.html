Evaluation Methodology

DeceptionGuard uses a unique hybrid intent-graph and evidence extraction architecture.

  • Intent Graph: Utilizes LLM extraction (or heuristic fallback) to understand the psychological pressure and requested actions in the email text.
  • Evidence Layer: Extracts hard indicators (link obfuscation, reply-to mismatch, DMARC failures, lookalike domains).
  • Risk Engine: Uses a weighted summation model capped at 100 for final risk scoring.

All evaluation metrics are calculated across a stratified dataset split using McNemar's test for significance.
